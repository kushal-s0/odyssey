# Owned speech and translation

The new speech path uses pinned Whisper large-v3-turbo on the owned laptop. PyAV decodes only the audio stream, so audio-only MP4 containers are accepted. Mono 16kHz samples are split into non-overlapping chunks of at most 28 seconds, with low-energy boundaries where possible. Silent chunks are omitted and recorded. Durable checkpoints retain each completed chunk; after interruption, acknowledged chunks are not recomputed.

Evidence time ranges are actual sample offsets for each chunk, not invented word timestamps. Source-language transcripts remain alongside their English renderings and private original recordings. Declared language and detected language are labelled separately; transcription uncertainty and human-review requirements remain visible. Base Whisper supports English/Hindi/Marathi/Telugu/Bengali. Explicit Odia input instead selects the pinned Apache-2.0 ARTPARK-IISc Vaani Odia model with at most ten-second chunks. Upstream forced decoder IDs are cleared; no Hindi language is forced. A 6.45-second sample produced 54 Odia characters in 24.007 seconds, but human-reference accuracy and full recordings remain unvalidated.

NLLB provides local translation for the six input languages. It loads a pinned snapshot and safe model weights without remote repository code or hosted inference. Token-length-based splitting avoids silent input truncation. Outputs that alter numeric tokens are flagged; uncertain segments are excluded from structured facts. Preserving digits alone does not establish a semantically correct translation, so source review is still required. NLLB's CC-BY-NC-4.0 license and research-use limitations are explicit in models/PROVENANCE.md.

These are existing pretrained third-party models. No new foundation-model training or measured population accuracy is claimed. Actual smoke measurements live under evals/reports/owned-speech.json and owned-translation.json. Original audio transcripts stay ignored under .local and are never uploaded to Groq or public model hosts. The API, database and worker retain the existing durable lease/fencing design.
