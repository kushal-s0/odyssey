# Evaluation, privacy and capacity

The private source-review workflow starts from immutable source hashes. `scripts/prepare_review.py` verifies all 55 inputs and builds an ignored offline PDF/audio form. Human labels require a reviewer, confirmed language, business-family group, split and exact reference. `evals/run.py` only measures reviewed test labels, rejects family leakage and reports null rather than zero-error metrics for missing denominators. English/Hindi reviewer availability does not mean review has occurred. The trained relevance candidate remains rejected; owned pretrained inference is a separate result.

Deletion begins with access and expected-revision checks. It locks/fences processing and sets a durable tombstone before removing any objects. That denies concurrent reads and stale publications while storage is unavailable. Each successful object delete records progress; repeated cleanup is safe. Only after originals are gone does the database cascade remove derived versions, evidence, vectors, reviews and caches. Minimal deletion audit metadata excludes source text. The explicit UI confirmation reflects irreversible final removal.

The public metadata JSON limit and larger worker publication limit are distinct from the authenticated private-upload limit. Body time/size bounds apply to streamed input as well as Content-Length. Existing MIME/container/page/audio bounds, output validation, capability fencing and trusted RLS scope continue at their own boundaries. Dependency audits are actual lockfile/environment observations, not a promise of permanent safety.

The measured local scale run used 10,000 synthetic metadata records, 50 virtual sessions sharing one synthetic applicant, two actual API processes and two tiny synthetic workers. A separate proxy exercised both replicas without sticky sessions; killing one worker recovered its durable checkpoint with one final publication. Query/index and aggregate memo improvements affect metadata, not inference throughput. Every cached chart request still reads trusted authorization and current revision metadata. A cache restart loses only temporary speed.

The final API container is lightweight and non-root, with no Torch or weights. Source/static archives are allowlisted and checked against actual configured private values. Building or packaging locally does not upload or deploy. Provider account quotas and public acceptance are separate required evidence.
