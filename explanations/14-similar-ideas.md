# Similarity

MiniLM is an existing frozen third-party encoder, not a project-trained model. It embeds only grounded offer/customer/problem text, with contact-pattern redaction. Its revision, preprocessing ID, summary hash and current input revision must match. Vector search happens inside the caller's database row-level-security scope. Other applicants' ideas therefore remain hidden unless a trusted role/cohort explicitly permits access. Revisions and repeated scenario families are excluded.

The UI explains matching trade/sector and compares actual offers/customers; it does not ask an LLM to invent relationships. Empty authorized sets and not-yet-indexed results are different states. New assessments are indexed in their normal worker publication; the bounded operator backfill command indexes existing results. Retrieval quality still requires positive and hard-negative human labels before reporting Recall@5.
