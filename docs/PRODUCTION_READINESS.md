# Readiness boundaries

This is a locally verified hackathon application with human review controls. It is not certified for production funding decisions. No public application deployment has been performed.

## Available now

Supabase-only login/persistence/private storage, applicant and scoped assessor workflows, durable model stages, immutable corrections/follow-ups, deterministic scoring/arithmetic, optional Groq explanations, sourced OSM context, similarity, comparisons, reports, responsive themes and explicit deletion are implemented. Software/access/browser checks and actual owned-model/provider smokes are recorded separately in the final checkpoint. Local API image and allowlisted release archives are prepared; they have not been uploaded.

## Required before making accuracy claims

Review the private original corpus with English/Hindi reviewers, correct unreadable OCR/ASR, group equivalent business families before splits and supply independent held-out field/evidence/retrieval labels. Add fluent reviewers for Marathi/Telugu/Bengali/Odia and paired equivalents before language fairness claims. Measure actual error numerators/denominators using `evals/run.py`; do not relabel machine translations as human truth. Recalibrate the rubric with the program owner. Scores support assessor understanding, not business-success probabilities or automatic funding approvals.

## Required before a hosted release

Obtain explicit publication approval for exact artifacts/destinations, verify actual Free account plans/quotas, set private API secrets and exact HTTPS origins, rebuild the frontend and run the complete deployed login-to-result/source/history/review/recovery matrix. Check forced token refresh/cross-cohort access against hosted services. Test backups/restores in a separately approved project and document deletion retention/recovery. Verify current NLLB licensing fits the intended use; choose an appropriately licensed measured alternative before commercial use.

The owned laptop must remain awake/connected; keep one GPU task on its 8 GB GPU. Hosted API sleep does not provide always-on inference. Optional Groq is quota-limited, OSM is incomplete and public providers must not be load tested. Do not enable billing, paid overages, borrowed public model endpoints or additional app databases to conceal an unmet gate. Secondary HF Spaces remain deferred/unverified and require separate provisioning/publication evidence.

## Honest release decision

Local app demonstration is supported with the specific model/source caveats shown in the UI. Population-accuracy, high-stakes automation, public deployment, unlimited scalability and fully cloud-hosted operation are unsupported claims. Open task states and earlier failed artifacts remain visible in `planning/TASK_STATUS.md`.
