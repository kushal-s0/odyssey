## Configuration, limits and operations

`STORAGE_BACKEND=supabase` is default. Explicit `local` is development/test only; production refuses it. Local files live under ignored `.local/private-storage` unless configured otherwise. No automatic local/paid fallback. No schema migration needed. Upload defaults: 25 MiB, 20 PDF pages, 600 decoded audio seconds, five unattached uploads/user, 60-second transfer timeout, 20-second parser timeout, one parser per API process. Linux parser adds CPU/address-space limits; actual Linux enforcement remains to verify. Shared queue default 20 active jobs and two/user. Temporary files are removed in `finally`. API original downloads are authenticated, hash-verified and no-store.

Cleanup is a trusted explicit command (`scripts/cleanup_uploads.py --execute`), max fifty >24-hour unattached objects per batch. It was tested locally; no hosted scheduler or cloud cleanup was executed. Manual cleanup/backup and eventual approved scheduling belong in deployment instructions.
